# Página web de San Antonio Alpanocan

Proyecto web comunitario para difundir información, tradiciones, proyectos, avisos y actividades relevantes de San Antonio Alpanocan.

## Objetivo

Crear una página web clara, moderna y accesible para fortalecer la identidad comunitaria, compartir información útil y documentar proyectos importantes para la comunidad.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Git
- GitHub
- Netlify

## Estado del proyecto

Proyecto en desarrollo inicial.
